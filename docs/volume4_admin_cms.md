# Volume 4 – Admin CMS

## 1. CMS Dashboard Overview
The dashboard features real-time metrics summarizing active articles, pending approvals, and visitor graphs. Built with a sleek dark aesthetic, incorporating glass panels and neon emerald charts.

## 2. Content & Listing Management
*   **Articles & Blog Editor**: WYSIWYG editor supporting custom components, responsive media blocks, and real-time SEO score checks.
*   **Personality Spotlight Manager**: Assign display weight, hero highlights, status tags, and timeline entries.
*   **Business Directory CMS**: Approve/reject submissions, verify business licenses, assign categories, and view locations.

## 3. Moderation & Comments Control
*   Global moderation queue for comment threads.
*   Profanity filtering integration + reports dashboard.

## 4. AI Copilot Tools
*   **Autogenerate Summary**: One-click summary creation using LLM integration.
*   **Tag Suggestion**: Automatically analyzes text and recommends appropriate taxonomy tags.
*   **SEO Meta Generator**: Instantly fills titles, meta descriptions, and alt tags for images.
